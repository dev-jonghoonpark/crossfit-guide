# 포즈 검사 스크립트

포즈를 고친 뒤 **애니메이션 중간 프레임**에 문제가 없는지 재는 도구다.
키프레임만 눈으로 봐서는 안 보이는 것들이라 손으로는 못 잡는다.

```bash
node tools/pose-check/bar-clearance.mjs bar-muscle-up   # 몸이 봉을 뚫고 지나가는가
node tools/pose-check/limb-fold.mjs                     # 팔·다리가 비정상적으로 접히는가
```

## bar-clearance — 봉 관통

철봉을 쓰는 동작에서, 두 키프레임 사이를 21 프레임으로 쪼개 몸통·다리 뼈가
봉(원)과 겹치는지 잰다. 손과 아래팔은 봉을 잡고 있으니 뺀다.
동작 id 를 인자로 주면 그 동작만 본다(기본값은 바 뮤스클업).

바 뮤스클업은 몸이 봉을 한 바퀴 돌아 넘어가는 유일한 동작이라, 가슴이 봉을
스치는 1 프레임만 남는 게 정상이다(그 순간은 실제로 봉이 몸에 닿는다).
그보다 많이 나오면 `data/poses.js` 의 BMU 주석에 적힌 세 가지 규칙을 확인한다.

풀업은 정점에서 `neck-shoulder` 가 걸리는데 이건 정상이다 — 턱이 봉을 넘은
자세라 봉이 턱·목 높이에 있는 게 맞다. 그 외 뼈가 걸리면 실제 문제다.

## limb-fold — 비정상 접힘

두 포즈 사이에서 팔꿈치·무릎이 접히는 **방향**이 뒤집히면, 보간이 "완전히
접힌 상태"를 지나가면서 손이 어깨에, 발이 골반에 닿는 가짜 자세가 만들어진다.
각 구간의 중간 프레임이 양 끝 키프레임보다 8 이상 더 접히면 잡아낸다.
0 이 아니면 그 구간의 팔꿈치·무릎 위치를 다시 봐야 한다.
